# 🏦 BankAccount Java OOP Exercise

## 📌 Objective
This exercise will help you practice the fundamentals of Object-Oriented Programming (OOP) in Java, including:
- Creating classes
- Using constructors
- Writing methods
- Working with objects

---

## 🧠 Problem Description

Create a Java program that models a simple **Bank Account system**.

---

## 🛠️ Requirements

### 1. Create a class called `BankAccount`

The class must have the following attributes:
- `accountHolder` (String)
- `balance` (double)

---

### 2. Add a Constructor

The constructor should:
- Accept `accountHolder` and `balance` as parameters
- Initialize the object’s attributes

---

### 3. Add Methods

#### ✅ `deposit(double amount)`
- Adds the given amount to the balance

#### ✅ `displayBalance()`
- Prints the account balance in the format: 
`Balance: R10000`

#### ✅ `getBalance()`
- Returns the balance 


---

## 🚀 Bonus Challenge (Optional)

Try adding:
- A `withdraw(double amount)` method
- Prevent withdrawing more than the available balance
